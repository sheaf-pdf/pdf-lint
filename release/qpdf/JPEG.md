# libjpeg

qpdf's macOS and Windows builds are statically linked with libjpeg-turbo, which is licensed under three licenses: the Independent JPEG Group's, for its libjpeg API library; the Modified (3-clause) BSD License, for its TurboJPEG API library and its SIMD extensions; and the zlib License, for parts of those extensions. Its copyright notices and full terms are in `libjpeg-turbo.copyright`, Ubuntu's copyright file for the library, which the Linux archives carry too.

As the Independent JPEG Group's license asks of an executable distributed without its source: this software is based in part on the work of the Independent JPEG Group.
