# Changelog

## 0.1.0 (unreleased)

- **The model.** The Arlington PDF Model's `tsv/latest` at `d148fee` (`COMMIT`), embedded by `build.rs`, with the cells corrected where it contradicts ISO 32000-2 or the reference it cites (`model/corrections.tsv`, `grammar::corrections`) and the rows and tables added that a reference defines and it lacks (`model/additions`, `grammar::additions`); the build stops when upstream has changed a corrected cell or has an added row itself. `grammar()` reads it once; `Grammar::load` reads a checkout whole, and `use_model` makes it the one `grammar()` gives. `Grammar::hash` is the XXH64 of a model's tables.
- **The tables.** A `Table` per object and a `Row` per key or element, upstream's 12 columns, the Type cell split into its `ArlType`s, a cell with an item per type into those items, and the version predicates around a type, a value or a link kept beside it (`Wrapped`, `Wrap`, `WrapFn`).
- **The predicates.** `predicate::parse` reads the language in the cells, which every predicate in the model prints back as; `required`, `holds`, `holds_fully`, `required_value`, `ignored`, `reference`, `since` and `gate` evaluate a cell on an object where it sits, a `Cx`, whose `resolve` closure gives the object a reference names. The 34 functions of `SUPPORTED` are evaluated, `fn:IsFullyQualifiedFieldName` among them, which this crate defines for the corrections; any other, or a value that can't be read, comes to `Truth::Unknown`, saying what's in the way.
- **Extensions.** `extension::declared` gives the extensions a file declares, as the model names them, from its trailer's `/Root`, its XMP metadata and a closure that gives the object a reference names, as its own; `extension::named` every extension the model names, and `extension::ISO` ISO's by number.
- **From pdf-lint.** These are pdf-lint 0.2.0's `grammar`, `predicate` and `extension` modules and the model, what they do unchanged, which pdf-lint re-exports where they were; `extension::declared` takes the catalog and the metadata in place of pdf-lint's `Source`, so the crate depends on pdf-objects' types alone, and `predicate::TOLERANCE` is public. `predicate::SUPPORTED` and `extension::ISO` are `&[...]`, not arrays of a fixed length, and `predicate::Expr` is `#[non_exhaustive]`, so a function, an extension or a form of predicate can come without a breaking release; `Grammar`, `Cx` and the caches have `Debug`; and `pdf_objects` is re-exported, so its types can be named at the version this crate takes. Rust 1.85 builds it.
- **Tests.** Every table of the embedded model reads, and its hashes are the references'; every predicate in it parses and prints back as written, with a census of its functions; each supported function means what INTERNAL_GRAMMAR.md says, on the model's own cells where it has them; the extensions declared, and every one the model names found; XXH64 against the reference's values; and the README's example as a doctest.
