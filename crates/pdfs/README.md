# pdfs

Read and write PDF files through one dependency. `pdfs` re-exports the crates of one family whole, so you name any of their types through it, at the versions it's built with, and get one set that works together: [pdf-tokenizer](https://crates.io/crates/pdf-tokenizer), [pdf-objects](https://crates.io/crates/pdf-objects), [pdf-filters](https://crates.io/crates/pdf-filters), [pdf-crypt](https://crates.io/crates/pdf-crypt), [pdf-structure](https://crates.io/crates/pdf-structure), [pdf-color](https://crates.io/crates/pdf-color), [pdf-content-streams](https://crates.io/crates/pdf-content-streams), [pdf-semantics](https://crates.io/crates/pdf-semantics), [pdf-fonts](https://crates.io/crates/pdf-fonts) and [pdf-linearize](https://crates.io/crates/pdf-linearize).

## Stability

This is an alpha: any alpha may change the API, and the CHANGELOG says how to follow. Depend on the exact version, `pdfs = "=0.1.0-alpha.1"`. It needs Rust 1.89 or later.
